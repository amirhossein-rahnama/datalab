# Compliance Checklist — {{project}}

> Generated by datalab. A lightweight, EU AI Act-aware checklist to work
> through before deploying or publishing this project. Not legal advice —
> consult your organization's compliance/legal team for regulated use cases.

## Risk Classification
- [ ] System's risk category assessed (minimal / limited / high / unacceptable per EU AI Act)
- [ ] Use case documented (see MODEL_CARD.md > Intended Use)
- [ ] Out-of-scope uses explicitly documented

## Data Governance
- [ ] Data sources documented (see DATA_CARD.md)
- [ ] PII scan run and findings addressed (`scripts/privacy.py`)
- [ ] Data license / usage rights confirmed
- [ ] Sensitive/protected attributes identified and handled deliberately

## Transparency
- [ ] Model card completed (`MODEL_CARD.md`)
- [ ] Data card completed (`DATA_CARD.md`)
- [ ] Users informed they are interacting with an AI system (if user-facing)
- [ ] Provenance manifest recorded for the shipped result (seed, versions, data hash, git commit)

## Technical Robustness
- [ ] Reproducible: fixed seeds, pinned dependencies (`requirements.txt`)
- [ ] Leakage-safe preprocessing (fit only inside CV folds)
- [ ] Baseline comparison beaten (Dummy/naive)
- [ ] Overfitting/underfitting checked (train-val gap, learning curve)
- [ ] Vulnerable dependencies scanned (`pip-audit`)

## Fairness & Human Oversight
- [ ] Subgroup performance evaluated; material disparities documented
- [ ] Explainability method applied (SHAP / importance / PDP)
- [ ] Human-in-the-loop / override mechanism defined for high-stakes decisions
- [ ] Monitoring plan for drift and performance degradation in production

## Accountability
- [ ] Owners/contacts listed (see MODEL_CARD.md)
- [ ] Incident/rollback plan documented
- [ ] Re-approval process defined for retraining or significant changes
