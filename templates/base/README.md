## Quickstart

```
python tasks.py setup   # pip install -r requirements.txt
python tasks.py lab     # launch Jupyter Lab (notebooks/01_eda.ipynb)
python tasks.py run     # run the full pipeline (pipeline.py)
python tasks.py test    # run the test suite
python tasks.py lint    # run ruff
python tasks.py report  # run just the report step of pipeline.py
```

`tasks.py` is a plain Python task runner — no `make` required, works the same
on Windows, macOS, and Linux.

## Reproducibility

Every run reads `config.yaml` for the fixed `seed` (default 42) and the
standard data paths. Keep every stochastic step (splits, model init, sampling)
seeded from `src/{{pkg}}/config.py`'s `SEED`.
